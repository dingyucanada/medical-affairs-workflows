# 慢病随访

用于已有明确诊断或明确复诊计划的人。先整理诊断和药品的原样信息、最近复诊及目标、相关记录、目前困扰、医生的后续安排和能去的机构。问清谁负责随访、怎样取得待出报告、何时联系谁、哪些变化需要按既有计划及时就医。中国基层随访资格和服务项目以当期文件及社区核实为准。 [国家卫健委 2026 年基本公共卫生服务通知索引](https://www.nhc.gov.cn/wjw/gfxwjj/list.shtml?keyword=1) · [WHO 慢性非传染性疾病综合管理](https://www.who.int/activities/integrated-management-of-ncds)

| 慢病主题 | 复诊可准备的内容 | 来源 |
| --- | --- | --- |
| 高血压 | 家庭测量的日期、条件和用药原单，记录近期变化和想问医生的目标。 | [心脏与循环](https://medlineplus.gov/bloodheartandcirculation.html) |
| 糖尿病 | 医生要求的血糖或其他监测记录、近期化验、低血糖相关事件和正在用药。 | [糖尿病](https://medlineplus.gov/diabetesmellitus.html) |
| 哮喘与慢阻肺 | 上次加重、诱因、吸入器清单与使用疑问，带既有急性加重处理计划。 | [肺与呼吸](https://medlineplus.gov/lungsandbreathing.html) |
| 心衰与稳定冠心病 | 既有复诊安排、运动耐受、症状及医生要求记录的体重或其他指标。 | [心脏与循环](https://medlineplus.gov/bloodheartandcirculation.html) |
| 慢性肾病 | 最新及既往肾功能、尿检、血压和所有药品或补充剂清单。 | [肾脏与泌尿系统](https://medlineplus.gov/kidneysandurinarysystem.html) |
| 骨质疏松与长期肌骨问题 | 已有骨密度报告、跌倒或骨折史、活动功能和上次医生给的计划。 | [骨骼、关节与肌肉](https://medlineplus.gov/bonesjointsandmuscles.html) |
| 慢性肝病 | 既有化验及影像时间线、精确用药和补充剂、医生交代的复查事项。 | [消化系统](https://medlineplus.gov/digestivesystem.html) |
| 风湿免疫疾病 | 疾病波动、影响功能的症状、治疗时间线和计划复查项目。 | [免疫系统](https://medlineplus.gov/immunesystem.html) |
| 长期精神健康问题 | 症状与功能变化、既有照护和安全计划、药品清单及关心的问题。 | [心理健康](https://medlineplus.gov/mentalhealthandbehavior.html) |
| 肿瘤治疗后随访 | 治疗摘要、已知后遗症、原专科随访计划、检查和新问题。 | [肿瘤](https://medlineplus.gov/cancers.html) |

多病共存时，把互相牵连的检查、药品和复诊窗口列出来，便于一位现有医生协调。家庭记录使用接诊团队指定的项目、单位与时间。对药物不良反应或调药问题，保留现行医嘱和疑问并交责任医生复核。新发严重或迅速恶化的情况先按[紧急情况](urgent.md)处理。
