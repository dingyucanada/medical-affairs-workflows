# 科室与就医导航

先判断是否有[需要立即处理的情况](urgent.md)。此索引按公众常见的就医入口与医技服务整理。医院的科室拆分、年龄限制、转诊与预约方式各有差异，使用本地机构的官方目录核实。临床问题同时涉及多系统、描述不清或需要协调慢病时，可以从全科、基层或已有接诊团队开始。 [医疗机构门诊名称管理通知](https://app.www.gov.cn/govdata/gov/202508/06/534257/article.html) · [医疗机构诊疗科目名录](https://www.wsjkw.cq.gov.cn/ztzl_242/fzjs/gz/gwybmgz/202006/t20200601_7527761.html)

## 常见就医入口

| 就医入口 | 可以协助整理的信息或任务 | 主题来源 |
| --- | --- | --- |
| 全科、家庭医学与基层医疗 | 多项不明确的非急性问题、健康维护、常规随访、跨科协调。 | [国家卫健委社区卫生服务](https://www.nhc.gov.cn/jws/c100073/202606/20c3486dc9ba4c09a9747547d4e841ad.shtml) |
| 急诊医学 | 可能危及生命、肢体或器官功能的情况，优先即时求助。 | [MedlinePlus 急症](https://medlineplus.gov/ency/article/001927.htm) |
| 综合内科 | 成人多系统的非急性问题、暂不明确的化验异常或既有内科病复核。 | [MedlinePlus 健康主题](https://medlineplus.gov/healthtopics.html) |
| 心血管内科 | 医生已关注的心律、血压、心功能或血管相关问题。整理既往心电图、用药和变化时间。 | [心脏与循环](https://medlineplus.gov/bloodheartandcirculation.html) |
| 呼吸与危重症医学门诊 | 已有呼吸问题、长期咳嗽或肺功能随访材料。区别预约门诊和当下呼吸急症。 | [肺与呼吸](https://medlineplus.gov/lungsandbreathing.html) |
| 消化内科与肝病门诊 | 消化道、肝胆和胰腺相关的非急性评估或复诊，整理症状和内镜、影像及化验。 | [消化系统](https://medlineplus.gov/digestivesystem.html) |
| 内分泌与代谢 | 糖尿病、甲状腺、骨代谢或其他既有激素代谢问题的资料准备与复诊。 | [内分泌系统](https://medlineplus.gov/endocrinesystem.html) |
| 肾内科 | 肾功能、尿蛋白或已确诊肾病随访。整理肌酐、尿检、用药和既有医生计划。 | [肾脏与泌尿系统](https://medlineplus.gov/kidneysandurinarysystem.html) |
| 神经内科 | 持续或反复的头痛、发作记录、感觉或运动变化、神经疾病复诊。突发严重症状按急诊处理。 | [脑与神经](https://medlineplus.gov/brainandnerves.html) |
| 血液内科 | 医生转诊的持续血常规异常、出血与凝血问题、已有血液病。保留多次检查及采样日期。 | [血液与循环](https://medlineplus.gov/bloodheartandcirculation.html) |
| 风湿免疫与变态反应 | 关节或多系统免疫问题、已确诊风湿病、过敏史和专科复评。 | [免疫系统](https://medlineplus.gov/immunesystem.html) |
| 感染性疾病门诊 | 传染病就医路径、暴露材料与已有诊断随访。具体发热门诊、预检或隔离安排由当地机构确认。 | [感染](https://medlineplus.gov/infections.html) |
| 肿瘤内科、放疗与肿瘤多学科门诊 | 已有影像或病理疑问、分型分期解释、治疗前咨询和随访材料。 | [肿瘤](https://medlineplus.gov/cancers.html) |
| 普外、胃肠外科与肝胆外科 | 已有手术转介、胆囊或腹壁等外科问题及术后门诊准备。 | [手术与康复](https://medlineplus.gov/surgeryandrehabilitation.html) |
| 乳腺、甲状腺和内分泌外科 | 机构分设时，可按检查部位和报告建议核实具体入口，携原始影像及报告。 | [手术与康复](https://medlineplus.gov/surgeryandrehabilitation.html) |
| 骨科与运动医学 | 稳定的骨关节、脊柱或运动损伤问题，整理外伤经过、功能影响和影像。 | [骨骼、关节与肌肉](https://medlineplus.gov/bonesjointsandmuscles.html) |
| 神经外科 | 已有神经外科转诊、医生评估过的颅脑和脊柱手术问题。 | [脑与神经](https://medlineplus.gov/brainandnerves.html) |
| 心胸与血管外科 | 已有胸部、心脏或血管手术评估需求，按转诊和既有检查确认院内入口。 | [手术与康复](https://medlineplus.gov/surgeryandrehabilitation.html) |
| 泌尿外科与男科 | 泌尿结构、结石或医生建议的泌尿外科评估。男科、生殖和泌尿门诊名称因机构而异。 | [肾脏与泌尿系统](https://medlineplus.gov/kidneysandurinarysystem.html) |
| 妇科、产科与生殖医学 | 妇科、备孕、生育、妊娠和产后就医信息，分别核对孕产急症和常规门诊。 | [妊娠与生殖](https://medlineplus.gov/pregnancyandreproduction.html) |
| 儿科、新生儿科与儿童保健 | 按年龄、问题和机构接诊范围区分普通儿科、新生儿和发育保健。 | [儿童与青少年](https://medlineplus.gov/childrenandteenagers.html) |
| 眼科 | 眼部和视力问题，准备变化时间、眼科报告及既有处方。突发严重症状先判断急诊。 | [眼与视觉](https://medlineplus.gov/eyesandvision.html) |
| 耳鼻咽喉头颈外科 | 听力、耳鼻、咽喉、吞咽或头颈评估，按机构专科设置核实。 | [耳鼻咽喉](https://medlineplus.gov/earnoseandthroat.html) |
| 口腔科与颌面外科 | 牙齿、牙周、口腔黏膜、颌面及口腔手术评估，区分不同口腔亚专科。 | [口腔与牙齿](https://medlineplus.gov/mouthandteeth.html) |
| 皮肤与性病科 | 持续皮肤、毛发、甲或专科性健康问题，整理变化及既往处理。 | [皮肤、毛发与指甲](https://medlineplus.gov/skinhairandnails.html) |
| 精神科、心理科与睡眠门诊 | 根据问题和机构能力选择评估入口，记录睡眠、情绪、功能变化及用药。即时安全危险优先求助。 | [心理健康](https://medlineplus.gov/mentalhealthandbehavior.html) |
| 老年医学 | 多种慢病、用药协调、行动和认知变化及照护安排，准备既有治疗计划。 | [老年健康](https://medlineplus.gov/olderadults.html) |
| 康复医学与疼痛门诊 | 既有诊断后的功能、活动目标、慢性疼痛复评和恢复计划，准备治疗限制与既往康复记录。 | [手术与康复](https://medlineplus.gov/surgeryandrehabilitation.html) |
| 临床营养与体重管理 | 饮食、体重趋势、疾病相关营养和医生建议的营养支持；区分一般健康教育和临床营养评估。 | [食物与营养](https://medlineplus.gov/foodandnutrition.html) |
| 遗传咨询与罕见病联合门诊 | 既有基因报告、长期不明的跨科症状、家族线索和第二意见材料。由现有团队或导诊查询机构入口。 | [NIH GARD](https://ncats.nih.gov/research/research-resources/gard) |
| 中医科与中西医结合 | 对照机构的正式门诊范围，汇总在用处方、草药与补充剂，便于不同团队核对。 | [国家卫健委基层服务](https://www.nhc.gov.cn/jws/c100073/202606/20c3486dc9ba4c09a9747547d4e841ad.shtml) |
| 医学影像、检验与病理 | 说明检查由哪个科室完成、如何获取报告、谁负责结合病情复核。已有报告通常带回开单团队。 | [MedlinePlus 检查索引](https://medlineplus.gov/lab-tests/) |

## 导航输出

用户给了医院时，核对官方科室目录、分院、接诊对象、预约条件与开诊信息。未给医院时，说明建议入口和一个合理备选即可。对跨科问题，把「先找谁协调」和「哪些部门负责相关检查」分开。
