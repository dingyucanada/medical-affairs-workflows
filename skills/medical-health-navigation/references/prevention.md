# 预防与健康维护

先分清用户是无症状的常规预防、正在出现症状，还是已经确诊后监测。体检和筛查的价值依赖年龄、风险、所在地、既往结果与可及性。先给可在基层或家庭医生处讨论的选项。

| 场景 | 如何帮助 |
| --- | --- |
| 常规体检与筛查 | 说明目标人群、筛查目的、可能的获益与查出偶然异常后的复核。遇到年龄阈值、间隔、停筛条件或支付政策，查用户所在辖区的现行正式资料。已经有症状者优先按症状咨询医疗人员。 |
| 免疫接种 | 整理既往接种时间和能取得的记录，区分常规、补种、旅行和职业需求。查当地官方免疫程序及个人情况是否需要专门咨询。 |
| 营养、运动、睡眠、口腔和生活方式 | 提供可理解、与用户目标相符的通用信息。把现有疾病、活动限制、孕期、儿童和高龄的要求交给对应专业指南或医护团队，避免推销补剂或疗效承诺。 |
| 儿童、孕产妇、老年人和照护者 | 按人生阶段整理家长或照护者可带的材料、常见保健主题、服务入口与当地安排。复诊由现有照护团队衔接。 |
| 职业、旅行及社区健康 | 基于暴露、目的地、时点和地区查公共卫生资源。办理要求、接种记录、职业评估和转介渠道以当地主管机构为准。 |

面向中国使用国家健康素养资料和本地卫健、疾控、社区门诊的正式信息。美国 USPSTF 仅用于美方推荐语境或明确的跨国比较。WHO 的全球材料可用于通用背景。 [中国公民健康素养释义](https://www.gov.cn/lianbo/bumen/202405/P020240530783730074981.pdf) · [WHO 免疫接种](https://www.who.int/health-topics/vaccines-and-immunization) · [WHO 身体活动](https://www.who.int/news-room/fact-sheets/detail/physical-activity) · [USPSTF 推荐主题](https://www.uspreventiveservicestaskforce.org/uspstf/recommendation-topics)
