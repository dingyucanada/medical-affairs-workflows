# 就医与健康导航参考来源

本表在 2026-11-24 整理。索引和通用资料用于查找；具体数值、筛查条件、政策和服务安排请回到当时适用的原文。

| 主题 | 参考及用途 |
| --- | --- |
| 中国门诊名称与科室结构 | 科室称谓和服务入口按医疗机构实际设置核对。 [国家卫健委等门诊命名通知](https://app.www.gov.cn/govdata/gov/202508/06/534257/article.html) · [重庆市卫生健康委刊载诊疗科目名录](https://www.wsjkw.cq.gov.cn/ztzl_242/fzjs/gz/gwybmgz/202006/t20200601_7527761.html) |
| 中国基层与社区就医 | 查基层和上级机构衔接、家庭医生服务和服务安排。 [国家卫健委社区卫生服务体系通知](https://www.nhc.gov.cn/jws/c100073/202606/20c3486dc9ba4c09a9747547d4e841ad.shtml) |
| 病种和人体系统 | 各科的来源入口供查具体问题。 [美国国立医学图书馆 MedlinePlus 健康主题](https://medlineplus.gov/healthtopics.html) |
| 急症信号 | 用于识别需要先求助的示例，实际紧急程度由医疗人员评估。 [MedlinePlus 急症说明](https://medlineplus.gov/ency/article/001927.htm) |
| 医学检查与报告 | 核查检查目的、结果、参考范围、单位和局限。 [MedlinePlus 检查](https://medlineplus.gov/lab-tests/) · [化验结果](https://medlineplus.gov/lab-tests/how-to-understand-your-lab-results/) |
| 诊断过程 | 用于理解信息收集、整合、工作诊断、复评和随访。 [美国国家科学院诊断过程章节](https://www.nationalacademies.org/read/21794/chapter/4) |
| 中国健康教育与保健 | 通用健康素养材料，服务地点和计划仍需核查辖区。 [健康素养释义 2024 版](https://www.gov.cn/lianbo/bumen/202405/P020240530783730074981.pdf) · [国家卫健委健康素养行动](https://www.nhc.gov.cn/xcs/c100123/202406/1b02d90b7f8a439181d1800af1f44989.shtml) |
| 筛查、免疫与运动 | 区分指南国家、主题和适用人群。美国推荐用于美方语境，WHO 主题用于全球背景。 [USPSTF](https://www.uspreventiveservicestaskforce.org/uspstf/recommendation-topics) · [WHO 免疫](https://www.who.int/health-topics/vaccines-and-immunization) · [WHO 身体活动](https://www.who.int/news-room/fact-sheets/detail/physical-activity) |
| 中国基层慢病 | 查当期通知与当地资格，用于对照可提供的随访服务。 [国家卫健委 2026 年通知 19 号所在公报](https://www.nhc.gov.cn/bgt/c100275cn/202611/e51b4299a4db450981b247ab5371a7ec/files/2026%E5%B9%B4%E5%9B%BD%E5%AE%B6%E5%8D%AB%E7%94%9F%E5%81%A5%E5%BA%B7%E5%A7%94%E5%91%98%E4%BC%9A%E5%85%AC%E6%8A%A5%E7%AC%AC8%E6%9C%9F.pdf) · [WHO 慢病管理](https://www.who.int/activities/integrated-management-of-ncds) |
| 中国罕见病目录与转诊 | 目录用于名称和政策范围查询，指南及协作网用于定位可核实路径。 [第一批目录解读](https://www.nhc.gov.cn/yzygj/c100067/201806/fb1b3d578fe04b98bb888931c3f84566.shtml) · [第二批目录](https://www.nhc.gov.cn/cms-search/downFiles/1b943db0e49348cab64f069b0f4cd9cf.pdf) · [2025 年诊疗指南发布说明](https://en.nhc.gov.cn/2025-07/11/c_86497.htm) · [协作网说明](https://www.nhc.gov.cn/wjw/jiany/202508/130709fc763843b8bf4c2ea7b41a0208.shtml) |
| 国际罕见病与遗传信息 | 查病名、患者资料、服务线索和报告术语。 [NIH GARD](https://ncats.nih.gov/research/research-resources/gard) · [Orphanet](https://www.orpha.net/en/diagnostic-tests/diagnostics) · [ACMG/AMP 变异解释共识](https://pubmed.ncbi.nlm.nih.gov/25741868/) |
