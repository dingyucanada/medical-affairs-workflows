# 一页就诊摘要

可以带到门诊。线上分享前移除姓名、证件、病案号、联系方式和影像中的标识。只填写有用的信息，未知项可留空。

## 本次要解决的问题

- 最想请医生确认的是……
- 症状或问题开始的时间、最近变化和对日常活动的影响……
- 当前正在发生的严重症状或明显恶化应优先联系急救或就医。

## 已掌握的事实

| 时间 | 症状、就诊或检查 | 报告或医生意见 | 待跟进事项 |
| --- | --- | --- | --- |
|  |  |  |  |

- 已有诊断、重要病史、手术、相关家族史和过敏……
- 当前药品、剂量及补充剂请按处方或包装原样记录……
- 随身携带完整报告或影像。关键化验保留项目、数值、单位和报告区间。

## 想向接诊医生确认

1. 现在已经明确什么？哪些仍需要核实？
2. 谁负责下一步，在哪复诊或领取报告，什么时候联系？
3. 哪些变化应提前联系诊疗团队或就医？
