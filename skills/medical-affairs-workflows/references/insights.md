# 洞察挖掘

## 从记录形成洞察

1. 从要影响的决定着手。先扫描疑似不良事件、质量投诉与特殊情况，例如妊娠暴露、用药错误、疑似疗效缺乏或装置故障。标出授权渠道待处理事项，再做内容分析。
2. 记录材料时间、来源与覆盖，区分原话、现场人员摘要和分析者推断。同一次互动的多条记录先归并，说明计数单位和可用分母。样本来自少数人员或地区时把覆盖偏倚带入结论。
3. 对一条观察，追问它为什么重要、会改变什么、有没有相反证据。对一批材料，保留矛盾、弱信号和未覆盖话题，按依据、覆盖及决策影响排序。少见而后果重大的线索可优先审查。出现频率与重要性各自说明。
4. 输出「洞察｜代表依据｜来源数量及分母｜把握与反例｜拟影响的决定｜建议动作及责任方」。样本数不足时可以交付质性判断和待验证假设。

## 竞品动态与专家互动

- **竞品科学动态**对登记、发表、学术会议和已批准说明书做同口径更新。保留数据截至日、状态确认时点和试验设计差异。说明实际改变了哪个判断，把相近产品跨试验的数字当成需要解释的间接信息。
- **专家简报、拜访前准备**基于公开且可核对的研究和经授权的既有交流，确定共同的科学问题、议题、证据材料及尚待闭环事项。用机构公开渠道和专业背景整理候选专家接触路径，避免推断私下关系或使用私人联系方式。
- **拜访后整理**记录实际讨论、问询、承诺、待核对信息及负责人。先处理可能涉及安全或质量的线索，保留事实与转述来源。准备 CRM 文字时保持草稿状态，确认授权和实际完成情况后再记作已提交或已跟进。
- **现场事务与数据接入**区分会前材料、拟安排活动、已发生、已记录、已完成跟进。读取已获准的导出或只读查询时记清字段、时间、范围、过滤、刷新日与缺漏。权限不足时先处理已有材料。
