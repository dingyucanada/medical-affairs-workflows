# 医学沟通与演示

从受众、用途、批准状态、目标决定和可用证据出发。先审内容边界，再做格式。使用用户指定的文件类型与品牌模板，标注草稿、数据截至日和审阅状态。直接回答简短问题时沿用简短形式。

## 幻灯、图文与通俗版本

- **非推广医学幻灯**每页数据标明设计、研究人群、样本量或分母、效应及区间、数据来源和局限。有效性和安全性按科学问题充分呈现。跨试验图形并排时交代不可比条件。产品优越性声称需有适当的证据。顾问会的内容应把待讨论的科学问题留给顾问。
- **可视化摘要**围绕一个明确结论，保留研究设计、样本、主要结果与重要限制。图和标题传达同一证据强度。
- **临床数据图**保留图形可读的分母、单位、时间和区间。生存曲线视数据提供风险集与删失信息。森林图给点估计、区间及无效线。瀑布图说明可评价人群、基线、变化定义及缺失。安全图列暴露和统计口径。
- **医学示意图**区分流程、已知关联、假设机制和证据强度。图形连线、方向或步骤来自可核对的资料。临床路径标出辖区、版本和适用人群。
- **通俗语言摘要**用受众能理解的文字给出研究对象、目的、观察结果和局限。能取得时用统一分母描述绝对风险与获益，说明中位数或其他统计量的实际含义。保留关键不确定性，避免个人治疗指示。语言可读性指标按对应语言使用。

## 对象、场合和内容运维

| 任务 | 交付要点 |
| --- | --- |
| 给管理层的简报 | 页首给判断、需要作出的决定、时点和选择。随后列出可追溯依据、风险与建议动作。 |
| 医学问询回复 | 记录对方主动提出的具体问题、地区和适用标签。以中性语气回应范围内的证据、局限和安全信息。对标签外问题及需升级事项按授权流程处理，标准答复注明版本。 |
| 医学信函 | 区分事实、请求和待确认的时间。按研究者、作者或顾问会对象安排语气、署名、附件和审批状态。 |
| 医学教育安排 | 从知识或实践差距写学习目标、受众及评价。区分独立教育和企业活动的内容责任、披露、组织及审阅要求。 |
| 安全性沟通 | 核对新事实、时间、措辞出处、批准状态、目标受众与渠道。写明已知和未知、适用人群与经批准的行动路径。对监管通告与正式报告转[药物安全与药政](safety-regulatory.md)。 |
| 患者参与安排 | 明确患者、照护者或组织要反馈的科学问题、可访问性、同意和保密、意见如何进入决策及反馈闭环。 |
| 会议记录 | 记录来源、说话人、决议、异议、开放事项和负责人。已有文字稿可直接整理。录音在授权环境内处理，低置信片段标注待确认。 |
| 现场上市培训 | 根据已核实的数据和批准状态准备培训、常见问询、证据边界、角色演练和疑似安全事件的升级路径。 |
| 医学内容维护 | 盘点材料、受众、渠道、版本、责任人、关键证据和上次审批。基于标签或重要证据变化决定更新、复用或撤回，并写触发依据。 |
| 支付与评估材料 | 区分研究证据、价值主张、相对疗效、预算影响和模型假设。列辖区、视角、时间范围、输入来源及情景不确定性。 |

## 送审和成稿复核

**推广材料医学核对**逐条查证疗效、安全性、平衡呈现、比较、批准标签与主张的匹配。**医学、法律和注册送审准备**核对结构、用途、受众、来源、材料版本和适用内部流程，标明尚待的审批。**成稿自查**对照原数据查数字、引用、措辞强度、图表可读性、交付完整性及前后口径。

复核稿可用「材料位置｜问题｜证据与依据位置｜影响｜建议行动或最小改写」。将科学核对意见交给相应责任人，由正式流程确认通过状态。
