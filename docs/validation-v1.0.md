# 重构与验证

## 版本范围

`medical-affairs-workflows` 1.0.0 是一个本地 Agent 技能。入口为 `SKILL.md`，按任务载入七个工作流。原条目的标题、版本和对应位置见 [64 条来源映射](../skills/medical-affairs-workflows/references/source-map.md)。证据状态与编辑动作采用一套规则，简短核查可以直接在对话中交付，文件生成遵循任务要求和宿主能力。

## 独立前向测试

三位独立测试代理分别读取入口和所需参考文件，用给定的虚构材料独立作答。复核检查决策、数字、待确认项和交付形式。

| 场景与输入 | 本次观察到的行为 |
| --- | --- |
| 审一页对外医学交流草稿。唯一摘要是 60 人单臂研究，12 周内 9 人住院。外部历史队列为 25%，未经调整。探索性年龄亚组缺少分母、区间和交互检验，DOI 无法取得。用户要可直接替换的文字。 | 保留 9/60（15%）和研究边界，收窄对所有成人的因果声称与老年组无效声称，把全文与正式引文列为待核，直接在对话中交付。 |
| 现场人员二手转述用药后住院，个例要素不齐，官方附件打不开。公开年报只给 80 条报告，缺暴露分母及其他报告计数。用户同时要个例记录、报送日和发生率。 | 给出待核实的个例记录与人工升级、追访事项，截止日保留未判定。将报告数保留为线索，明确发生率、比例失衡与验证结论各自缺什么。 |
| 未获批产品距目标上市日十周，团队总计 100 小时。培训、医学问询和安全演练分别要 35、25、15 小时。顾问会和大会材料另需 35、45 小时。 | 先排三项共 75 小时的必做工作，留 25 小时缓冲，暂缓两个提案。列出获批前可做的内部工作、待批准后才能定稿的部分和延期时的重新排程条件。 |

## 验证边界

已通过技能格式、全部 64 条映射及其章节、内部链接、上游署名文件和 ZIP 完整性检查。前向测试使用虚构例题，覆盖证据审查、药物警戒和上市规划。真实接口、企业审批流程及跨客户端运行效果尚未实测。
