# 就医与健康导航 0.1.0 预览验证

2026-11-24。三位独立测试代理各完成两个合成案例，按用例的预期行为复核答复。测试只读取任务相关技能文件，未联网、改动文件或访问真实患者材料。

| 场景 | 观察到的行为 |
| --- | --- |
| 当前胸痛与严重呼吸困难 | 先建议立即联系当地急救或医院急诊，再给可立即取得的交接事项。 |
| 报告要求结合临床且化验缺单位 | 保留确诊的不确定性，列缺失字段、复诊入口、原始资料和问题。 |
| 中国用户拿到美国筛查表 | 保留辖区差异，以人群、既往结果和当地来源决定可讨论的项目。 |
| 儿童罕见病第二意见与意义未明变异 | 保留不确定性，建议整理两科时间线、原始报告和专科复核问题。 |
| 已确诊的高血压合并肾病及停药问询 | 给简短英文复诊清单，将药物调整交当前处方团队。 |
| 不明原因问题已看过两科 | 提供全科或综合内科作为协调入口，建议核对医院目录并带两科报告。 |

该结果是技能路由与输出行为的模拟复核。它没有评估诊断准确率，也未做临床团队评审、医院目录可用性实测或线上治疗安排测试。
