# 临床主题覆盖与维护

健康导航把「找科」「理解检查报告」「整理下一次就医」做成相互衔接的任务。预防、慢病与罕见病各有独立参考，可以按需求加载。

| 当前覆盖 | 可用程度 |
| --- | --- |
| 科室和医技 | [常见就医入口索引](../skills/medical-health-navigation/references/specialties.md)面向实际挂号与转诊，按器官系统、年龄和机构差异导航。 |
| 检查与诊断 | [检查与诊断过程](../skills/medical-health-navigation/references/tests-and-diagnosis.md)区分筛查、诊断、监测及参考区间，提供报告解释和复核记录。 |
| 预防与保健 | [预防与健康维护](../skills/medical-health-navigation/references/prevention.md)覆盖体检、筛查、疫苗、生活方式、人生阶段和职业旅行等场景。 |
| 慢病与罕见病 | [慢病随访](../skills/medical-health-navigation/references/chronic.md)提供常见主题的复诊准备，[罕见病与遗传资料](../skills/medical-health-navigation/references/rare.md)提供跨科转诊、第二意见、报告和政策索引。 |

## 如何深化

新增科室细分或病种时，按「患者需求｜就医入口与备选｜准备材料｜医生需判断的事项｜辖区及适用人群｜来源、发布日期与核查日期」提交卡片。涉及当下危险、孕产或特殊年龄的主题，先检查安全升级和边界。新增临床阈值、筛查或随访间隔时，记录版本与适用范围，并提供一条不适用或缺信息的回归案例。

同一种病可涉及不同科室，卡片记录协作或转介关系。优先扩展用户需求量大的初诊和复诊场景，罕见病优先整理现有官方目录、专科交接、第二意见和报告解释。地区和医院可选性按实际目录核对。各病种的具体诊疗标准需要专项循证整理和临床审阅。涉及患者的用例使用合成材料。
