# 行为评测

[合成案例](cases.json)覆盖中英文任务、失败检索、证据声称、药物警戒、历史规则、上市资源和适用范围。用例中的数字、产品和法规片段为测试素材。复跑时只将 `prompt` 交给测试代理，保留 `expected_route`、`rubric` 和 `critical_failure` 供复核人评分。

1. 在临时测试仓库创建 `.agents/skills/`，复制本技能到该目录，开启新会话。使用给定输入和语种，并记录客户端、模型、工具可用性和所读参考文件。
2. 每题单独运行。逐条核对 `rubric`，记录是否发生任何 `critical_failure`。重要行为变化优先在同样环境下重跑旧版和新版。
3. 比较增益时补做同模型的无技能对照，避免隐式加载同名技能。记下初次运行结果、缺失和例外。用合成材料完成回归，不上传生产材料。

仓库 CI 运行格式、内部链接、证据台账单元测试和打包检查。模型行为用例需要另行运行，与软件测试结果分开记录。正式监管环境的复核、提交和客户端适配需要各自验证。
